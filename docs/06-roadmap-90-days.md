# 90-Day Roadmap & Milestones (Phase 1)

Week-by-week, tickable. The only goal that matters: **paying clients and the beginning of recurring revenue by day 90.** Building comes second; selling comes first. This is Phase 1 of the [Masterplan](00-masterplan.md); months 4–24 continue in the [Scaling Roadmap](07-scaling-roadmap.md).

## Days 1–14 — Foundation

**Goal: able to sell by day 14.** Definition of done: niche chosen, stack live, 2 demos recorded, offer page online, payment method ready.

Week 1:
- [ ] Choose niche (criteria in [Go-To-Market](04-go-to-market.md)); write the one-sentence outcome offer
- [ ] Set up VPS + Docker + self-hosted n8n; Claude API account; Supabase project ([stack](03-tech-stack-and-architecture.md))
- [ ] Set up payments: Stripe (or Wise/Payoneer fallback), invoice template, deposit policy
- [ ] Start demo #1: support chatbot on realistic content for your niche

Week 2:
- [ ] Finish demo #1; build demo #2 (the niche's #2 pain: lead follow-up, invoice extraction…)
- [ ] Record a 2–3 min Loom for each demo
- [ ] One-page website: headline, demos, 3 services with "from $X" prices, call-to-action
- [ ] Upwork profile live, tuned to "AI automation / chatbot / n8n" keywords
- [ ] Contract + proposal templates ready ([Operations](05-operations-legal.md))
- [ ] List 100 target companies in the niche (name, contact, observed pain)

## Days 15–45 — First revenue

**Goal: 1–2 paying projects delivered.** Definition of done: money received, first testimonial + case study collected.

Daily rhythm (non-negotiable, ~2h/day when not delivering):
- [ ] 10–15 personalized outreach touches/day (warm network first, then the 100-list)
- [ ] 5 tailored Upwork proposals/day, each with a relevant demo link
- [ ] All follow-ups sent (3-touch sequence)

Weekly:
- [ ] 1 prospect-specific demo built and sent (the demo-first motion)
- [ ] Friday: pipeline review — touches, replies, calls, proposals, wins

Milestones:
- [ ] Day ~21: first discovery calls happening
- [ ] Day ~30: **first paid project signed** (cheap-but-not-free + testimonial/case-study/referral deal in writing)
- [ ] Day ~40: project #1 delivered and accepted (test cases passing); testimonial collected
- [ ] Day 45: project #2 signed or in negotiation

**Day-30 go/no-go:** ≥300 touches sent, ≥5 calls held. If yes but zero clients → offer/niche problem: change the outcome sentence or the niche, not the tools. If touches < 150 → discipline problem: fix the calendar before blaming the market.

## Days 46–90 — Systemize

**Goal: recurring revenue exists.** Definition of done: **$2,000–5,000/month run rate, of which $500–1,500 MRR from 3–5 retainers.**

- [ ] Raise project prices 25–50% (you have proof now)
- [ ] Pitch every delivered client the retainer at handover ("who maintains this when the API changes?") — tiers in [Pricing](01-business-model-and-pricing.md)
- [ ] Export every delivered workflow + prompts + test cases into the private template library
- [ ] Write case study #1 with real numbers; put it on the site; ask for the promised referrals
- [ ] Approach 3–5 web/marketing agencies for white-label partnership
- [ ] Keep the daily outreach rhythm (reduced to ~8–10 touches/day while delivering)
- [ ] Day-60 checkpoint: ≥2 projects delivered, ≥1 retainer signed, pipeline ≥5 warm conversations — else diagnose: pricing? niche? delivery speed?
- [ ] Day-90 review: revenue math, hours per client, which service sold best → double down on that service/niche, then enter **Phase 2** of the [Scaling Roadmap](07-scaling-roadmap.md) (voice services, more categories, VA hire)

## Weekly KPIs (track every Friday, 10 minutes, one spreadsheet)

1. Outreach touches sent (target: 50–75/week)
2. Calls booked (target: 2–4/week by week 4)
3. Proposals/demos sent (target: 3–5/week)
4. Revenue collected this week
5. Retainer MRR total

If a number is red two weeks in a row, change the activity behind it, not the spreadsheet.

## How people fail in the first 90 days

- **Building instead of selling.** Perfecting demo #4 while sending zero outreach. The stack from [docs/03](03-tech-stack-and-architecture.md) is enough — stop improving it.
- **Tool-hopping.** Every new framework restarts your learning curve and ships nothing. n8n + Claude API until $5k/month, then reconsider.
- **Underpricing forever.** The plan says raise prices at day 46. Do it even though it feels scary — especially then.
- **One giant client.** A single client at >40% of revenue turns you into their employee with extra risk. Keep prospecting.
- **Silent pipeline death.** Delivery weeks with zero outreach create the feast-famine cycle. The daily touches are the business.
