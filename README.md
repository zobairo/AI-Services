# AI-Services — Business Plan: AI Automation Service Provider

A practical, executable plan for starting a business that **builds and runs AI-powered automations for paying clients** — chatbots, document processing, lead-gen, and workflow automation — as a solo technical founder starting from zero.

## The business in one paragraph

Small and mid-size businesses drown in repetitive communication and document work. You sell them the outcome — "your website answers every customer in 10 seconds, 24/7", "invoices enter the accounting system by themselves" — delivered with a boring, reusable stack (Claude API + self-hosted n8n + Supabase). Get in the door with a productized entry offer, charge a fixed build fee, then convert every client to a **monthly retainer** (hosting, monitoring, improvements). The retainer base is the real business; the private library of reusable workflow templates is the real asset.

## Headline numbers

| What | Number |
|---|---|
| Lead services | AI support chatbot · workflow automation with AI steps |
| Build fees (starting → established) | $500–1,500 → $2,000–5,000+ per project |
| Retainers | $100–800/month across 3 tiers |
| Infra cost per client | ~$35–50/month (healthy margin at every tier) |
| Day-90 goal | $2,000–5,000/month run rate incl. $500–1,500 MRR from 3–5 retainers |
| Month 7–12 goal | $5,000–10,000/month |

## How to use this repo

1. Read [04 — Go-To-Market](docs/04-go-to-market.md) first and pick your niche — every other decision depends on it.
2. Work through the [90-Day Roadmap](docs/06-roadmap-90-days.md) checklists in order; days 1–14 make you able to sell.
3. Come back to the other docs when the roadmap points at them (pricing a deal, signing a client, setting up the stack).
4. Treat the numbers as anchors, not laws — adjust to your market, and update the docs as reality teaches you.

> Prices and targets are estimates for a solo founder serving SMB clients in 2026; local markets vary. The legal/ops doc is practical guidance, not legal advice.
